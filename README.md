# 诗笺 · 古诗词学习工作台

一个离线可用的古诗词学习工具。内置 80 首经典篇目（唐诗、宋词、元曲、诗经、汉魏），每首配一句赏读；加入背诵本后按艾宾浩斯遗忘曲线自动排复习，到期进入「今日该复习」清单。

## 功能

| 模块 | 说明 |
| --- | --- |
| 诗词库 | 按朝代 / 题材 / 关键词检索，支持搜标题、作者、正文句子、赏读 |
| 今日推荐 | 每天根据日期自动换一首，打开就有得读 |
| 背诵本 | 艾宾浩斯间隔复习（0/1/2/4/7/15/30/60 天），「记得」进下一档，「忘了」归零重来 |
| 默写自测 | 随机挖空 35% 的汉字，填完即时判分，可换一组空、可看答案 |
| 飞花令 | 输入一个字，检索诗库中所有含该字的句子，点句跳转原诗 |
| 数据备份 | 背诵记录导出 / 导入 JSON |

## 快速开始

不需要安装任何东西，不需要联网：

```
双击 index.html
```

如果想用本地服务器打开（改代码时更方便）：

```bash
cd poetry-studio
python -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 目录结构

```
poetry-studio/
├── index.html          页面骨架
├── assets/
│   ├── style.css       样式（宣纸配色，无外部字体依赖）
│   └── app.js          全部交互逻辑，原生 JS，无框架
└── data/
    └── poems.js        诗库数据，80 首
```

## 技术栈

纯静态页面，零依赖、零构建步骤。HTML + 原生 CSS + 原生 JavaScript，数据存在浏览器 `localStorage`。

## 数据说明

- 背诵记录保存在浏览器本地，不上传、不注册、不联网。
- 换设备或换浏览器请用「关于」页的导出 / 导入搬家。
- 清空浏览器数据会一并清掉背诵记录，重要进度记得先导出。
